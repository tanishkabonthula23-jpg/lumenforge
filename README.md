# LumenForge

Modern multi-page professional website built with HTML, CSS, JavaScript & jQuery.

## Features
- 4 fully designed pages (Home, About, Work, Contact)
- Smooth animations & micro-interactions
- Two different carousel styles
- Typing effect, animated counters, modal
- Fully responsive
- Clean modern teal + gold design system

## Live Demo
After enabling GitHub Pages: `https://yourusername.github.io/lumenforge`

## How to run locally
Just open `index.html` in your browser or use any local server.
